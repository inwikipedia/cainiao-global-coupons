Comment utiliser un code promo

Suivez ces quatre étapes pour appliquer le code promo de votre destination à la caisse des envois groupés Cainiao.

01

Ouvrir Cainiao

Consultez le site d’information officiel du service d’expédition Cainiao ou son application provenant d’une boutique officielle.

02

Choisir la destination

Sélectionnez le pays de livraison et le service de consolidation proposé.

03

Saisir le bon code

Collez le code du pays concerné dans le champ « Promo Code » au paiement.

04

Confirmer la réduction

Vérifiez la réduction appliquée, les frais supplémentaires et le montant total à payer.

Questions fréquentes

À savoir avant d’utiliser un code

Comment utiliser ces codes promo?

Chaque destination possède son propre code. Copiez le code correspondant et collez-le dans le champ « Promo Code » à la caisse des envois groupés Cainiao : la réduction sur les frais de livraison est calculée automatiquement.

Où faut-il entrer le code promo Cainiao?

Cherchez un champ « Promo Code » ou « Coupon » au paiement de la livraison internationale et collez le code de votre destination.

Peut-on cumuler le rabais avec d’autres offres?

La page de paiement indique les offres cumulables avec le code et le plafond de réduction. Suivez les invites à l’écran pour appliquer toutes les réductions disponibles.

Key takeaways

  • Match the code to the destination and the selected route.
  • Check minimum spend, account eligibility and stacking rules.
  • The discount appears in the total, not just in a status message.

Before you start

Have the shipment built: parcels selected, route chosen, packing options added. A code tested on an incomplete order can behave differently from one tested on the final order.

Take a screenshot of the total before applying anything. You will need it for comparison.

The checklist

Work through these in order. Stop at the first mismatch.

  1. Destination: does the code match the delivery country? AUONLY for Australia, USONLY for the US, and so on.
  2. Route: is the selected shipping method included in the promotion? Some codes exclude express, sea freight or sensitive-goods routes.
  3. Minimum spend: does the shipping fee meet the threshold? A code only applies once the minimum is reached.
  4. Account: is the promotion limited to new users, verified accounts or specific regions?
  5. Stacking: is another discount already applied? Some offers are mutually exclusive.
  6. Time and quota: is the promotion within its active period and usage quota?
  7. Total: did the amount drop? The new total is the confirmation that the code applied.

What “applied” should look like

An applied code adds a discount line to the fee breakdown and reduces the amount due. A message that says “code entered” or “coupon selected” is only the first step — the total is the confirmation.

If the total changes by an amount you did not expect, check whether the discount is capped or calculated on the base shipping fee only.

If the code does not apply

Do not create multiple orders to keep testing. Remove the code, confirm the route and total against the checklist, and try again or switch to another eligible route. The mismatch is usually one of the seven items above.

Never move to a private chat or an off-platform payment page because someone offers a “better code”. That is a common scam pattern.

No legitimate promo code requires your password, SMS code or a payment to a personal account.

Record what worked

Keep a note of the date, destination, route, code and the total before and after. Over a few orders, you will see which routes give you the best all-in price and when each promotion runs.

That record turns this checklist into a repeatable routine for every shipment.

Frequently asked questions

Why does a code work for my friend but not me?

Eligibility can depend on destination, route, account status, region or quota, so run the same checklist against your own shipment.

Can I apply a code after paying?

Usually no. Most checkouts lock the amount after payment, so apply the code before you complete payment.

Is a screenshot of a discount enough?

A screenshot only shows someone else’s checkout. Apply the code on your own order — the total on your screen is what matters.

本文要点

  • 体积重 = 长×宽×高÷抛比系数，单位统一用厘米。
  • 计费重取实重和体积重的较大值，轻抛货几乎都按体积重。
  • 换小箱、压缩软物、拆掉礼盒，通常比找优惠码更能省钱。

公式与单位

常见公式是：体积重（kg）= 长（cm）×宽（cm）×高（cm）÷抛比系数。抛比系数由承运方设定，常见 5000、6000、8000，也有按立方米计价的线路。

测量时量外箱最凸出的部分，包括胶带和加固材料。仓库量的是打包后的箱子，不是你买的时候的包装尺寸。

抛比系数为什么不同

系数反映运输工具的空间成本。空运舱位贵，系数通常更小（同样体积算得更重）；海运和铁路空间相对充裕，系数可能更大。系数越小，体积重越高。

这也是为什么同一个小箱子，走空运和走海运的计费重可能差很多。比较线路时，不能只比每公斤单价。

快速判断你的包裹是不是轻抛货

用这个简单方法估算：

  1. 量出外箱长宽高，算出体积（cm³）。
  2. 用体积除以线路抛比系数，得到体积重。
  3. 和实重比较，体积重明显更大就是轻抛货。
  4. 如果体积重是实重的 1.5 倍以上，优先考虑换箱或压缩。
不确定系数时，先用 6000 估算，再去看线路页确认。估算只用于决策，最终以仓库测量为准。

降低体积重的五个动作

按效果从高到低排列：

  • 换小箱：让仓库找更贴合商品的箱子，减少空隙。
  • 压缩软物：衣物、被子、玩偶用真空袋或压紧。
  • 拆礼盒/鞋盒：鞋盒占空间但不保护鞋本身，可拆。
  • 拆分大件：可拼装家具拆成平板，按最长边计费更划算。
  • 减少填充物：过度气泡膜会撑大体积，适度即可。

什么时候不该压体积

易碎品、精密仪器、乐器等需要缓冲空间，强行压缩会增加破损风险。高价值商品还应加保价。省运费的底线是不增加货损概率。

如果你在选线路，可以对照空运 vs 海运：时效、计费与适合的货看体积重对总价的影响。

常见问题

体积重和实重哪个算钱？

取较大者。轻抛货按体积重，密度高的货按实重。最终计费重以仓库打包后的测量为准。

自己量尺寸有用吗？

有用。下单前估算能帮你决定是否换箱、拆包或换线路；出库后如有争议，自己量的数据也是核对依据。

所有线路都按体积重吗？

多数国际线路都计体积重，但系数和进位方式不同，少数线路按固定体积单价。以线路页为准。

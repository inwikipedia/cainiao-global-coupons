本文要点

  • 先确认代码与目的地匹配，再在结算页找 Promo Code 输入框。
  • 输入后必须看到总价变化，才算真正生效。
  • 失效先排查目的地、门槛、互斥和时间，不要反复提交订单。

优惠码在哪里输入

常见位置有三个：运费结算页的“优惠码/Promo Code”输入框、订单确认页的“使用优惠”入口、支付前的费用明细页。不同平台叫法不同，找不到时看页面底部或“更多优惠”。

如果整个流程都没有输入框，可能是当前线路、地区或账户不支持，不代表代码本身无效。

怎么判断真的生效

输入后点“应用/使用”，观察费用明细是否出现折扣行，总价是否下降。只看到“已输入”不算生效。

截图保存应用前后的总价，付款后如果金额不对，这是最直接的证据。

失效的五步排查

按顺序排查，通常能定位原因：

  1. 目的地：代码是否对应你的收件国家（如 AUONLY 对应澳大利亚）。
  2. 线路：活动是否只限特定运输方式或包裹类型。
  3. 门槛：是否要求最低运费、最低重量或新用户。
  4. 互斥：是否与其他折扣、优惠券、活动价冲突。
  5. 时间与名额：活动是否已结束或名额用完。
如果页面提示“无效”，不要为了试码反复下单。先看活动规则，或换一个结算时段再试。

常见问题

优惠码可以叠加吗？

通常不能，或只能与特定活动叠加。以结算页提示和活动规则为准，不要假设可以累积。

代码对所有线路都有效吗？

不一定。很多活动只限特定线路、包裹类型或账户。先看规则，再测试。

付款后才发现没用上怎么办？

多数平台不支持事后补用。联系客服说明情况，但不保证能退差。付款前确认总价是最稳妥的。

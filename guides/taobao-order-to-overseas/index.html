本文要点

  • 先确认商家是否支持海外配送，再决定直邮还是寄集运仓。
  • 集运仓地址要完整填写识别码，收件人按仓库要求填。
  • 卖家发货后立刻用快递单号预报，别等入库才处理。

下单前的三个确认

在点“提交订单”之前，先确认这三件事：

  • 能否配送：商品页是否支持你所在国家，或是否支持国内配送（可寄集运仓）。
  • 是否禁运：电池、液体、食品、品牌仿品等可能被线路拒收。
  • 收货地址：直邮填海外地址，集运填仓库地址+识别码。

收货地址怎么填

直邮时按平台格式填海外地址，注意州/省、邮编、门牌号和电话。集运时填仓库地址，收件人姓名按仓库指定格式，识别码不能漏。

建议在淘宝地址簿里建两个地址：一个海外直邮，一个集运仓。命名清楚，下单时不会选错。

支付与发货

选好商品后按平台支持的支付方式付款。卖家发货后，订单页会显示国内快递公司和单号。复制单号，去集运后台做入库预报。

如果卖家迟迟不发货，先在平台催发货；超过承诺时间可申请退款。不要私下转账给卖家。

官方直送和集运怎么选

官方直送通常由平台合作物流承运，流程简单，适合单件或少量商品。集运适合多店铺、多包裹、需要拆包减重的情况。

两者不是互斥的：有的订单直送，有的订单寄集运仓，最后在目的地汇合。

直送与集运的差异
维度官方直送集运仓
操作复杂度低中，需要预报和合单
适合订单单件/少量多店铺/多包裹
首重每单计可合并
拆包减重通常不支持支持（视仓库）
时效较稳定取决于合单和线路

发货后的动作清单

复制快递单号 → 集运后台预报 → 关注入库状态 → 核对重量和数量 → 合单 → 付款 → 查国际轨迹。

每一步的细节可以看包裹入库预报与签收核对：别让包裹变成无主件和合单怎么合：哪些包裹该一起寄，哪些要分开。

常见问题

淘宝可以直接寄到国外吗？

部分商品和商家支持官方直送或直邮，具体看商品页和收货地址是否可选。不支持时，可寄到集运仓再转寄。

地址填错了怎么办？

未发货可取消重下；已发货联系卖家改址或拦截；已签收错地址通常需要人工转运，费用自理。

卖家不发货能退款吗？

可以，按平台规则申请。注意保留聊天记录，不要脱离平台私下交易。
